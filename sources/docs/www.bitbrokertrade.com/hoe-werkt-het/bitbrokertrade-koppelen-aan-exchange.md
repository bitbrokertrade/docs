# BitBrokerTrade koppelen aan exchange

Zodra je een rekening bij een exchange hebt geactiveerd en er euro's op hebt gestort kun je de BitBrokerTrade software koppelen aan de rekening bij de exchange. Via een API koppeling kan de trader met jouw rekening communiceren en jouw aan- en verkoopopdrachten doorgeven.

[Video](https://www.bitbrokertrade.com/media/tcbbc0ym/bbt-koppelenaccounts.mp4) [Stap voor stap](https://www.bitbrokertrade.com/hoe-werkt-het/bitbrokertrade-koppelen-aan-exchange#steps)

Dit heb je nodig om de accounts te koppelen:

- Account bij één van de vier beurzen
- API publieke sleutel (public key)
- API prive sleutel (private key)
- Google Authenticator

[aanmelden](https://bitbroker.trade/Authentication/Register)

## API koppeling stap voor stap

### Stap 1

Log in bij de exchange (in dit voorbeeld Bitvavo) en klik op je gebruikersnaam. Er klapt een menu open en daarin kies je voor 'Instellingen'

![Stap 1 Telefoon Verifieren](https://www.bitbrokertrade.com/media/bjnheau5/stap-1-telefoon-verifieren.jpg?anchor=center&mode=crop&width=750&height=423&rnd=132361834327070000)

### Stap 2

Eerst gaan we het telefoonnummer verifiëren. Kies voor de blauwe button "Verifiëren" en doorloop alle vervolg stappen.

![Stap 2 Telefoon Verifieren](https://www.bitbrokertrade.com/media/0aomowcj/stap-2-telefoon-verifieren.jpg?anchor=center&mode=crop&width=750&height=423&rnd=132361836100830000)

### Stap 3

Nadat het telefoonnummer geverifieerd is, gaan we de 2 factor verificatie invoeren. Je hebt daarbij Google Authenticator app nodig. Zorg dat die geïnstalleerd is op je smartphone. Klik op de groene button "Inschakelen" en doorloop de stappen.

![Stap 3 Twee Factor Authenticatie](https://www.bitbrokertrade.com/media/dr5pa1k0/stap-3-twee-factor-authenticatie.jpg?anchor=center&mode=crop&width=750&height=423&rnd=132361838841770000)

### Stap 4

Klik nu weer op je gebruikersnaam en kies voor "API".

![Stap 4 API Koppelen](https://www.bitbrokertrade.com/media/l3unqidm/stap-4-api-koppelen.jpg?anchor=center&mode=crop&width=750&height=423&rnd=132361841503630000)

### Stap 5

Kies vervolgens voor "Nieuwe API Key aanvragen"

![Stap 5 Api Koppelen](https://www.bitbrokertrade.com/media/y1jixwan/stap-5-api-koppelen.jpg?anchor=center&mode=crop&width=750&height=423&rnd=132361842342070000)

### Stap 6

Vul het scherm in als hiernaast weergegeven. Uiteraard wel je eigen twee-factor code gebruiken!

![Stap 6 Api Koppelen](https://www.bitbrokertrade.com/media/4vhe3g4l/stap-6-api-koppelen.jpg?anchor=center&mode=crop&width=750&height=423&rnd=132361843103970000)

### Stap 7

Kopieer nu de API Key met de daarvoor bedoelde button

![Stap 7 Api Koppelen](https://www.bitbrokertrade.com/media/kx2futz5/stap-7-api-koppelen.jpg?anchor=center&mode=crop&width=750&height=423&rnd=132361844632870000)

### Stap 8

Log in bij BitBrokerTrade, ga naar Instellingen/Beuzen/Beurs toevoegen/Bitvavo en kopieer je API sleutel op de bedoelde plaats en kies voor "Toevoegen".

![Stap 8 Api Koppelen](https://www.bitbrokertrade.com/media/1p0pdnrt/stap-8-api-koppelen.jpg?anchor=center&mode=crop&width=750&height=423&rnd=132361846144570000)

### Stap 9

Bevestig API Key bij Bitvavo en kies vervolgens voor 'Verifiëren". De API verbinding is nu actief.

![Stap 9 API Koppelen](https://www.bitbrokertrade.com/media/z3kgbend/stap-9-api-koppelen.jpg?anchor=center&mode=crop&width=750&height=423&rnd=132361847338970000)
