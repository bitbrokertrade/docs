Markdown versions of documentation pages are available by appending \`.md\` to page URLs; this page is available as \[Markdown\](https://docs.bitbrokertrade.com/exchanges/binance-toevoegen-als-beurs.md). # Binance toevoegen als beurs ## API koppeling maken voor Binance Nadat je bent ingelogd op de website van Binance klik je op je accountnaam (weergegeven met je initialen, zie onderstaande afbeelding). !\[\](/files/-M4EY-C-Vuqtg6F4xlLb) Zodra je op je accountnaam geklikt hebt, verschijnt er een menu. In dit menu kies je voor \*\*"API Management"\*\* Bij \*\*"Label API key to proceed"\*\* vul je de naam van je API Key in: bijvoorbeeld \*\*"BitBrokerTrade".\*\* Daarna druk je op \*\*"Create API".\*\* Er ontvouwt zich nu een tweede scherm: !\[\](/files/-M4EaNfqqxb1FA8uLcEd) Vul de \*\*"API restrictions"\*\* in zoals bovenstaande afbeelding en kopieer de API Key met de daarvoor bedoelde \*\*"Copy"\*\* button. Het systeem kopieert automatisch de API key, zodat je die bij BitBrokerTrade in je account kunt plakken. Hetzelfde geldt voor de API secret. Denk er wel aan om de API via de aan jou gezonden mail te activeren. \*\*Je kunt de API sleutel bij BitBrokerTrade pas activeren nadat je de bevestigingsmail van Binance hebt bevestigt\*\* (in geval van 2FA met google authenticator is er geen bevestigingsmail)\*\*.\*\* ## Beurs activeren Bij BitBrokerTrade klik je allereerst in de linker kolom op \*\*"Instellingen"\*\*, vervolgens op \*\*"Beurzen"\*\* en daarna op \*\*"Beurs toevoegen"\*\*. !\[\](/files/-M3f2JvxGsAsiUEDfyp7) Kies vervolgens voor \*\*"Binance"\*\* door op het logo te klikken !\[\](/files/-M3f2Jvyw1PMecaBXG1w) Vul bij de naam "\*\*Binance\*\*" in. !\[\](/files/-M3f2JvzGW9lxIaPwBmb) Kopieer de sleutels zoals eerder aangegeven maar klik pas op toevoegen als je de bevestigingsmail van Binance over de API Key bevestigd hebt of je 2FA met Google Authenticator in het Binance menu hebt afgerond. "\*\*Schakel gereserveerd bedrag in\*\*" geeft je de mogelijkheid een reservering in te brengen. Het bedrag (in euro's) wat hier ingegeven is houdt de trader vrij van (her)investering. \*\*Dit bedrag wordt dus niet gebruikt om aankopen te doen\*\*. Voorbeeld: Je eurosaldo op de beurs is € 1.000,- en je hebt een gereserveerd bedrag van € 250,- ingegeven. De trader rekent dan alleen met posities tot € 750,-. Er blijft altijd € 250,- beschikbaar op je euro rekening bij de Exchange. Wanneer dit allemaal gebeurd is gaan we door naar de volgende stap. ### \*\*De trader koppelen aan de beurs:\*\* !\[\](/files/-MR4ezPADrY5RHem8AAX) Geef de volgende zaken in: 1. de naam van de beurs en de cryptovaluta waar je in gaat handelen: bijvoorbeeld: \*\*Binance Bitcoin\*\*. 2. Kies uit het menu: \*\*"Binance".\*\* 3. Kies uit het menu de juiste valuta combinatie, bijvoorbeeld: \*\*BTC/EUR.\*\* 4. Kies uit het menu de juiste handelsstrategie: \*\*BitBrokerTrade.\*\* 5. Hier vul je het winstpercentage in waarbij de trader over mag gaan tot verkoop van de positie. 6. Geef een koers (in euro's) voor deze munt in waarboven geen posities meer mogen worden ingenomen. 7. Als je wilt dat posities met vaste bedragen worden ingenomen, geef je hier dat bedrag in. 8. Hoeveel openstaande posities mag de software maximaal tegelijk innemen voor deze munt. 9. Door hier een vink te plaatsen activeer je de trader. \*\*Gefeliciteerd, uw trader werkt!\*\*
