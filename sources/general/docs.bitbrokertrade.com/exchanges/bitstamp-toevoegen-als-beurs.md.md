Markdown versions of documentation pages are available by appending \`.md\` to page URLs; this page is available as \[Markdown\](https://docs.bitbrokertrade.com/exchanges/bitstamp-toevoegen-als-beurs.md). # Bitstamp toevoegen als beurs !\[Koppel gemakkelijk een beurs met deze handleiding\](/files/-M3f6Hfkpx9CIu-iCzxf) ## \*\*API koppeling maken voor Bitstamp\*\* Nadat je bent ingelogd op de website van Bitstamp klik je op \*\*"Security"\*\* (zie onderstaande afbeelding). Vervolgens klik je op \*\*"API Acces"\*\*. !\[\](/files/-M3f5xWI-cyf3Cci2aSd) Zodra je onderstaande ziet kun je klikken op \*\*"NEW API key"\*\* (staat er een bestaande key, verwijder die dan eerst). !\[\](/files/-M3f5xWJUYE5TWqu1s4o) Je krijgt dan het volgende scherm te zien, vul hier niets in en scroll verder naar beneden: !\[\](/files/-M3f5xWK9XBr2w781aYS) Scroll totdat je dit te zien krijgt: (de buttons bij de rode pijltjes dien je met je muis naar rechts te zetten zodat ze er uitzien als in de fabeelding). !\[\](/files/-M3f5xWL4m9Ayyed\_eKx) Onderaan het scherm zie je de bevestigingsbutton. Klik hierop en vul je 2FA code in vanuit de app op je telefoon. !\[\](/files/-M3f5xWMUhjp06q6Crqb) Daarna kopieer je in volgorde de volgende codes naar de nieuwe beurs/exchange bij BitBroker.trade !\[\](/files/-M3f5xWNIly-PPtj37iY) Door op het vakje te klikken van de code, kopieer je gemakkelijk de API key, zodat je die bij BitBrokerTrade in je account kunt plakken. Hetzelfde geldt voor de API secret. \*\*Je kunt de API bij BitBrokerTrade pas activeren nadat je op de bevestigingsmail van Bitstamp hebt geklikt.\*\* Bij BitBrokerTrade klik je allereerst in de linker kolom op "Instellingen" en vervolgens op "Beurzen". Daarna klik je rechts op "Exchange toevoegen". Kies vervolgens voor Bitstamp door op het logo te klikken !\[\](/files/-M3f5xWOqkrkYbw726ix) Dan krijg je het onderstaande venster: !\[\](/files/-M3f5xWPxXpcftSTRw5A) Vul bij "Naam" je accountnaam in van Bitstamp. \*\*NOG NIET OP TOEVOEGEN KLIKKEN\*\*. Eerst zorgen dat bij Bitstamp de API geactiveerd is (door de bevestigingsmail van Bitstamp te bevestigen). Kopieer de sleutels zoals eerder aangegeven maar klik pas op toevoegen als je de bevestigingsmail van Bitstamp eerst hebt geaccordeerd. "\*\*Schakel gereserveerd bedrag in\*\*" geeft je de mogelijkheid een reservering in te brengen. Het bedrag (in euro's) wat hier ingegeven is houdt de trader vrij van (her)investering. \*\*Dit bedrag wordt dus niet gebruikt om aankopen te doen\*\*. Voorbeeld: Je eurosaldo op de beurs is € 1.000,- en je hebt een gereserveerd bedrag van € 250,- ingegeven. De trader rekent dan alleen met posities tot € 750,-. Er blijft altijd € 250,- beschikbaar op je euro rekening bij de Exchange. ## BitBrokerTrade Trader koppelen aan Bitstamp Kies in de trader voor menu \*\*"Instellingen"\*\* en vervolgens voor \*\*"Traders"\*\* en dan voor \*\*"Trader toevoegen".\*\* Het volgende scherm verschijnt: !\[\](/files/-MR4kFwDjsfhF5gW4QIT) Geef de volgende zaken in: 1. de naam van de beurs en de cryptovaluta waar je in gaat handelen: bijvoorbeeld: \*\*Bitstamp Bitcoin\*\*. 2. Kies uit het menu: \*\*"Bitstamp".\*\* 3. Kies uit het menu de juiste valuta combinatie, bijvoorbeeld: \*\*BTC/EUR.\*\* 4. Kies uit het menu de juiste handelsstrategie: \*\*BitBrokerTrade.\*\* 5. Hier vul je het winstpercentage in waarbij de trader over mag gaan tot verkoop van de positie. 6. Geef een koers (in euro's) voor deze munt in waarboven geen posities meer mogen worden ingenomen. 7. Als je wilt dat posities met vaste bedragen worden ingenomen, geef je hier dat bedrag in. 8. Hoeveel openstaande posities mag de software maximaal tegelijk innemen voor deze munt. 9. Door hier een vink te plaatsen activeer je de trader. \*\*Gefeliciteerd, uw trader werkt!\*\*
