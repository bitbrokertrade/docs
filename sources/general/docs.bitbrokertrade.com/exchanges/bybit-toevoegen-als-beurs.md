## Account aanmaken bij Bybit

Indien je nog geen account bij Bybit hebt, ga eerst naar www.bybit.com en kies daar voor het aanmaken van een inlogmogelijkheid.

**Wat heb je nodig:** Werkend emailadres, Paspoort, Mobiele telefoon, Telefoonnummer en de Google Authenticator app.

Nadat je een inlog hebt aangemaakt en je je opgegeven email geverifieerd hebt (door een mailbericht van ByBit te bevestigen), kies je in het hoofdmenu voor 'Identity Verification'. Je gaat nu een KYC traject (KYC = Know Your Client) in waarbij je ByBit gaat bewijzen dat jij bent wie je zegt dat je bent (m.b.v. een paspoort of identiteitskaart), en je je persoonlijke bankrekening en je telefoonnummer opgeeft.

Je komt in het volgende scherm:

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252FLAx5v1mLWenJGcDbtdnp%252FIdentity%2520verification%2520Bybit.JPG%3Falt%3Dmedia%26token%3D3c38236c-3078-4092-a7fb-996d61a6457c&width=768&dpr=3&quality=100&sign=4038c91b&sv=2)

Kies hier voor "Verify Now"

Vervolgens krijg je een aantal schermen, waarvan onderstaande de eerste is. Als je de schermen doorlopen hebt, heb je de verificatie procedure doorlopen.

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252FSF4LEfeIMJHDyCdHHOby%252FIdentity%2520verification%2520Bybit%25202.JPG%3Falt%3Dmedia%26token%3D3736937e-378f-4a95-943c-a64417c57bcf&width=768&dpr=3&quality=100&sign=359c467c&sv=2)

Het kan een paar uur duren voordat je verificatie ook bij ByBit is goedgekeurd.

## API sleutel aanmaken in ByBit

Nadat je geverifieerd bent kun je in het hoofdmenu rechtsboven via het persoonlijke icoon kiezen voor een uitklapmenu. Kies hierin voor "API". Het volgende scherm verschijnt:

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252FCjZd36dFDPBKM6uBA6cy%252FBybit_1.jpg%3Falt%3Dmedia%26token%3Da97d3b02-4259-4b92-b719-cbed9895f688&width=768&dpr=3&quality=100&sign=ec41ad4&sv=2)

Kopieer je API sleutel en je API Secret sleutel naar je kladblok. Je hebt deze beiden zometeen nodig in de BitBrokerTrade applicatie.

Kies voor "Understood"

Je bent nu klaar met het API proces in Bybit.

## Sluit ByBit en gaan naar BitBrokerTrade

Ga naar menu Instellingen/beurzen en kies voor de button "Beurs toevoegen"

Selecteer "ByBit"

Voer de API sleutels in die je naar je kladblok hebt gekopieerd en kies vervolgens voor "Toevoegen".

De API verbinding wordt direct getest en de status wordt "actief".

De volgende stap is het activeren van een trader voor de ByBit omgeving.
