Markdown versions of documentation pages are available by appending \`.md\` to page URLs; this page is available as \[Markdown\](https://docs.bitbrokertrade.com/exchanges/bybit-toevoegen-als-beurs.md). # ByBit toevoegen als beurs ## Account aanmaken bij Bybit Indien je nog geen account bij Bybit hebt, ga eerst naar \[www.bybit.com\](http://www.bybit.com) en kies daar voor het aanmaken van een inlogmogelijkheid. \*\*Wat heb je nodig:\*\* Werkend emailadres, Paspoort, Mobiele telefoon, Telefoonnummer en de Google Authenticator app. Nadat je een inlog hebt aangemaakt en je je opgegeven email geverifieerd hebt (door een mailbericht van ByBit te bevestigen), kies je in het hoofdmenu voor 'Identity Verification'. Je gaat nu een KYC traject (KYC = Know Your Client) in waarbij je ByBit gaat bewijzen dat jij bent wie je zegt dat je bent (m.b.v. een paspoort of identiteitskaart), en je je persoonlijke bankrekening en je telefoonnummer opgeeft. Je komt in het volgende scherm:

![](https://docs.bitbrokertrade.com/files/suhKhCvO9OtyNJAWpNNC)

Kies hier voor "Verify Now" Vervolgens krijg je een aantal schermen, waarvan onderstaande de eerste is. Als je de schermen doorlopen hebt, heb je de verificatie procedure doorlopen.

![](https://docs.bitbrokertrade.com/files/BKDaFasxwt6ul0kyldlB)

Het kan een paar uur duren voordat je verificatie ook bij ByBit is goedgekeurd. ## API sleutel aanmaken in ByBit Nadat je geverifieerd bent kun je in het hoofdmenu rechtsboven via het persoonlijke icoon kiezen voor een uitklapmenu. Kies hierin voor "API". Het volgende scherm verschijnt:

![](https://docs.bitbrokertrade.com/files/huCkVJ4gtfT7aJn00dW0)

Kies: "Create New Key" Als je nog geen 2FA authenticatie hebt ingesteld krijg je het volgende scherm:

![](https://docs.bitbrokertrade.com/files/EhWRmM1QPE36THLpwe6B)

Nadat je 2FA met Google Athenticator hebt geinstalleerd, kun je verder met de het volgende scherm (opgedeeld in 2 afbeeldingen). Let op dat je bij de instellingen "withdrawals" \*\*niet\*\* activeert!

![](https://docs.bitbrokertrade.com/files/lXIzthHRPADCq0na3mX6)

![](https://docs.bitbrokertrade.com/files/WlpxLAp8qO9KKax2aZow)

Klik op "submit" en het volgende scherm verschijnt:

![](https://docs.bitbrokertrade.com/files/x6bQ3YwjppN5oDZgXWOR)

Kopieer je API sleutel en je API Secret sleutel naar je kladblok. Je hebt deze beiden zometeen nodig in de BitBrokerTrade applicatie. Kies voor "Understood" Je bent nu klaar met het API proces in Bybit. ## Sluit ByBit en gaan naar BitBrokerTrade Ga naar menu Instellingen/beurzen en kies voor de button "Beurs toevoegen" Selecteer "ByBit" Voer de API sleutels in die je naar je kladblok hebt gekopieerd en kies vervolgens voor "Toevoegen". De API verbinding wordt direct getest en de status wordt "actief". De volgende stap is het activeren van een trader voor de ByBit omgeving.
