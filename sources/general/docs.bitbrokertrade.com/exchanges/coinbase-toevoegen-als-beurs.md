## API koppeling maken voor Coinbase advanced

Nadat je bent ingelogd op de website van **Coinbase** klik je links in de menubalk op "**Meer**".

Ga daarna in hetzelfde scherm naar de optie **"Advanced API":**

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252FDK5FB1LChk01iYx3xasc%252Fcoinbase_api_1.jpg%3Falt%3Dmedia%26token%3Dd677d8ec-a72d-437b-92f7-804391ea7971&width=768&dpr=3&quality=100&sign=cee35eab&sv=2)

Je krijgt nu een nieuw scherm. Daar kies je voor de optie **"Uw API-sleutel maken".**

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252FBygIC0zpSFGXFGGeBmVU%252Fcoinbase_api_2.jpg%3Falt%3Dmedia%26token%3D9817baaa-764e-4e97-bd7e-c4760409dcbe&width=768&dpr=3&quality=100&sign=ff0b91e2&sv=2)

Daarna verschijnt een scherm en kies je voor "**API-sleutel maken**".

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252FkfU25Ho7B0WOhVWD1ICa%252Fcoinbase_api_3.jpg%3Falt%3Dmedia%26token%3D09783463-26b6-43ea-bb5b-93943c08f015&width=768&dpr=3&quality=100&sign=a1318d3f&sv=2)

In het pop up scherm doe je het volgende:

**Je geeft je sleutel een naam**.

Bij "**Portefeuille**" kies je voor 'standaard'.

Vink "**View"** en "**Trade**" aan.

Bij "**IP Whitelist**" vul je niets in. Je laat staan wat daar al staat (het voorgedrukte is een nep IP).

Kies vervolgens voor "**Maken en downloaden**".

Met het ".json" bestand wat wordt opgeslagen, hoef je niets te doen. Onze applicatie ondervangt dat.

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252FmXc6ffzWNMWZIuAAfGYu%252Fcoinbase_api_4.jpg%3Falt%3Dmedia%26token%3D48ef3672-da12-432d-ba13-6a6a97e6dcee&width=768&dpr=3&quality=100&sign=cecc7dbc&sv=2)

Er verschijnt nu een pop up scherm met je twee API sleutels (gewoon en secret). Kopieer deze naar je kladblok of ga direct naar BBT (zie hieronder) en kopieer ze daar gelijk naar het bedoelde menu.

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252FMmBZdi8du7Ilx323utL3%252Fcoinbase_api_5.jpg%3Falt%3Dmedia%26token%3D9ceda926-6081-410c-814f-2460212c361e&width=768&dpr=3&quality=100&sign=1f01edda&sv=2)

Je aanmaak van de API key is nu klaar. Je hebt op je kladblok nu 2 dingen staan: **API Secret Key en API Key**.

Klik op "**Ik heb mijn sleutel opgeslagen**".

Vervolgens **log je in bij Bitbrokertrade** en ga je naar het menu "**Instellingen**" en dan naar "**Beurzen**". Daar kies je vervolgens voor "**Beurs toevoegen**".

Selecteer "**Coinbase advanced**", er verschijnt een invulmenu waar je je bewaarde gegevens kan invullen:

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252F3QLw49AcVss5VfNdUb0n%252Fcoinbase_api_6.jpg%3Falt%3Dmedia%26token%3Dbe9eada1-2f66-4ab8-9ef2-49859ab645d7&width=768&dpr=3&quality=100&sign=6a6bf3d2&sv=2)

Kies voor "**Toevoegen**" en je verbinding met Coinbase advanced is actief!

De volgende stap is het koppelen van een trader aan de Coinbase verbinding. Ga daarvoor naar: [https://docs.bitbrokertrade.com/traders/trader-toevoegen](https://docs.bitbrokertrade.com/traders/trader-toevoegen)
