Markdown versions of documentation pages are available by appending \`.md\` to page URLs; this page is available as \[Markdown\](https://docs.bitbrokertrade.com/exchanges/kucoin-aanmaken-als-beurs.md). # Kucoin aanmaken als beurs ## Account aanmaken bij Kucoin Indien je nog geen account hebt bij Kucoin, ga dan eerst naar \[www.kucoin.com\](http://www.kucoin.com) en kies daar voor het aanmaken van een inlog. \*\*Wat heb je nodig:\*\* Werkend emailadres, Paspoort, Mobiele telefoon, Telefoonnummer en de Google Authenticator app. Nadat je de inlog hebt aangemaakt en het KYC traject (KYC=Know Your Client) hebt doorlopen kun je je spotsaldo funden. Let erop dat BitBrokerTrade werkt vanuit je beschikbare Eurosaldo. ## API sleutel aanmaken in Kucoin Je kiest in het startscherm voor het persoonlijk icoon rechtsboven in het scherm en in het uitklapscherm kies je voor API.

![](https://docs.bitbrokertrade.com/files/j74iDYdOQxuhmGWq2Yi6)

Vervolgens kies je voor \*\*"API aanmaken"\*\*

![](https://docs.bitbrokertrade.com/files/GUzsWJV7JtTvL0T6jW6H)

In het volgende scherm geef je de API een \*\*naam\*\* en verzin je een \*\*wachtwoord\*\*. Vink de twee rubrieken \*\*"Spothandel"\*\* en \*\*"Geen Limiet"\*\* aan en klik op \*\*"Volgende"\*\*

![](https://docs.bitbrokertrade.com/files/T8zcrGJWYznx3Ny2FVwQ)

In het volgende -popup- scherm worden je API sleutels getoond. \*\*Kopieer deze naar je kladblok: je hebt die straks nodig in BitBrokerTrade om de koppeling te maken. Dat geldt ook voor je verzonnen API wachtwoord.\*\*

![](https://docs.bitbrokertrade.com/files/dIl4Sbm4XZMSaPpzlIyg)

Je bent nu klaar met het API proces bij Kucoin. ## Sluit Kucoin en ga naar BitBrokerTrade Ga naar menu \*\*Instellingen/beurzen\*\* en kies voor de button \*\*"Beurs toevoegen"\*\* Selecteer "Kucoin"

![](https://docs.bitbrokertrade.com/files/K1W4D3SiogNIzGOyItQL)

Voer de API sleutels in die je naar je kladblok hebt gekopieerd, voer het API wachtwoord in en kies vervolgens voor \*\*"Toevoegen".\*\* De API verbinding wordt direct getest en de status wordt \*\*"actief".\*\* De volgende stap is het activeren van een trader voor de Kucoin omgeving.
