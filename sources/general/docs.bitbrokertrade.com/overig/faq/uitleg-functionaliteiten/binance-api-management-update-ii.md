Hieronder is beschreven hoe dat in zijn werk gaat:

## Stappenplan:

Log in bij Binance en ga naar het menu API management

Klik op de gele vinkbalk (zie afbeelding):

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252F3mk9Fp12eAHgKK1hxiLs%252FBinance%2520api%25201.png%3Falt%3Dmedia%26token%3Dcce66e9a-dea5-48fc-87ce-ae8041daab08&width=768&dpr=3&quality=100&sign=d8114563&sv=2)

Een pop up scherm opent zich:

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252FZMxixnaGoBtzsypgS2oX%252FBinance%2520api%25202.png%3Falt%3Dmedia%26token%3Dbc263701-e0d8-470b-af10-31dadbedc34c&width=768&dpr=3&quality=100&sign=d6cd2784&sv=2)

Binance geeft je hier de mogelijkheid om “Default Security Controls for Unrestricted API Keys” uit te zetten. Dit is precies wat we gaan doen.

Scroll de bar aan de rechterzijde van het pop up scherm volledig naar beneden. Je markeert daarmee de tekst als gelezen en je kunt nu een een vink in de gele vinkbox zetten.

Kies “Confirm”

Vervolgens komt er een nieuwe pop up met een “Risk Warning”, zodat je echt bewust bent dat je afwijkt van de standaard instellingen:

Kies “Confirm”:

![](https://docs.bitbrokertrade.com/~gitbook/image?url=https%3A%2F%2F845056123-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F-Ly4NKRJzL8JZvlE5PJs-887967055%252Fuploads%252FNPxbJtj8GmxOJ21hib9n%252FBinance%2520api%25203.png%3Falt%3Dmedia%26token%3D04049b44-d9b1-4980-9dd9-02891c0de91c&width=768&dpr=3&quality=100&sign=f570f7d7&sv=2)

Vervolgens moet je de authenticator code en een code die je per email ontvangt (let op: je moet daarvoor op ‘**get code’** drukken) ingeven.

**Je kunt vanaf nu weer ‘Enable spot & Margin Trading activeren’ bij je API codes, ook als je geen whitelisted IP adres hebt.**
