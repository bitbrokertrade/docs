![](https://docs.bitbrokertrade.com/files/IZh4JLx6NXhJnOkXe4mZ)

Een pop up scherm opent zich:

![](https://docs.bitbrokertrade.com/files/YtsZffTsUzFr4CkZit7E)

Binance geeft je hier de mogelijkheid om “Default Security Controls for Unrestricted API Keys” uit te zetten. Dit is precies wat we gaan doen. Scroll de bar aan de rechterzijde van het pop up scherm volledig naar beneden. Je markeert daarmee de tekst als gelezen en je kunt nu een een vink in de gele vinkbox zetten. Kies “Confirm” Vervolgens komt er een nieuwe pop up met een “Risk Warning”, zodat je echt bewust bent dat je afwijkt van de standaard instellingen: Kies “Confirm”:

![](https://docs.bitbrokertrade.com/files/e4mkI1ihwBX4hUZTzoWy)

Vervolgens moet je de authenticator code en een code die je per email ontvangt (let op: je moet daarvoor op ‘\*\*get code’\*\* drukken) ingeven. \*\*Je kunt vanaf nu weer ‘Enable spot & Margin Trading activeren’ bij je API codes, ook als je geen whitelisted IP adres hebt.\*\*
